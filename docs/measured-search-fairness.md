# Measured search fairness

Measured comparisons require every Stage 7A fairness anchor plus the exact cohort/objective hashes. Records must share device fingerprint, target, compiler build, runtime, benchmark configuration, distribution, dimensions, validation policy, and record count. Cross-device/build/input/config pooling rejects.

Complete, bounded, cancelled, failed, terminal, unmeasured-terminal, eligible, and ineligible outcomes remain separate. Correctness proofs, production validation, search replay, measurement eligibility, measured values, task success, learned ranking, confidence tests, and timing observations are reported independently. Synthetic fixtures support contract reproducibility only. No p-value, confidence interval, portability, global optimum, or policy-speed claim is invented from record summaries.
