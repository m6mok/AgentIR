# Ranking metrics

Stage 6B reports raw choice-set size distributions, top-1 acceptance/progress rates, selected compiler-order position, tie/collision frequency, override/escape rates, accepted escapes, ranked rejections, repair cycles, context bytes per choice, tokens per decision, completion, budget exhaustion, and semantic task-criterion rates.

Metrics are recomputed from transcripts. Missing external tokens remain unknown. There is no unversioned weighted overall score, hidden oracle regret, or claim that the selected action is globally best.
